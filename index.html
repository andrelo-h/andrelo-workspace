Folder structure
Copy this to your computer. Click folders to expand or collapse.
Why this structure
01-clients/ — One subfolder per client keeps all files, contracts, invoices, and assets together. Never search for a client file again.
02-portfolio/ — Live demos ready to show instantly. Case studies ready to post on Contra and LinkedIn. Screenshots for content creation.
03-products/ — Where client patterns become reusable systems. Start filling this when you see the same problem across three clients.
04-content/ — Batched by week. Raw recordings separate from edited exports. Never lose an asset or confuse a draft with a final.
05-business/ — One proposal template you reuse forever. Contracts, invoices, and your finance tracker in one place.
06-learning/ — Notes and code experiments that belong to no client project.
